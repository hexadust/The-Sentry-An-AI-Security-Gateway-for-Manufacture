# The-Sentry-An-AI-Security-Gateway-for-Manufacture
The Sentry adalah smart device AIoT yang berperan sebagai security gateway berbasis Raspberry Pi untuk lingkungan manufaktur guna mencegah phishing dan ancaman rekayasa sosial secara real-time melalui AI/ML, sandbox Docker, serta dashboard monitoring sebagai visualisasi, guna mencegah serangan sebelum masuk ke sistem operasional produksi
